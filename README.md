# customer-feedback-sentiment-analyzer
Project Capstone - Customer Feedback Sentiment Analyzer pake IBM Bob
# Penganalisis Sentimen Umpan Balik Pelanggan

Proyek Capstone - Analisis Sentimen Umpan Balik Pelanggan menggunakan IBM Bob

## Deskripsi Proyek
Proyek ini menganalisis umpan balik pelanggan untuk mengetahui apakah sentimennya Positif, Negatif, atau Netral. Tujuannya membantu perusahaan memahami kepuasan pelanggan dengan cepat.

## Fitur
- Menganalisis teks umpan balik secara otomatis
- Mengklasifikasikan sentimen: Positif, Negatif, Netral
- Menampilkan ringkasan hasil analisis

## Cara Menjalankan
1. Buka file `analyzer.py`
2. Jalankan dengan Python: `python analyzer.py`
3. Atau jalankan di Google Colab

## Teknologi yang Digunakan
- Python
- IBM Bob (untuk bantuan pengembangan)

## Struktur File
- `analyzer.py` : Kode utama untuk analisis sentimen
- `Requirements.txt` : Daftar kebutuhan proyek
